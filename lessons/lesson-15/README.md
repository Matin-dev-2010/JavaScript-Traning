# درس 15: sort()

`sort()` آرایه را درجا تغییر می‌دهد؛ برای اعداد comparator لازم است. برای حفظ آرایه اصلی کپی بگیر.

```js
const ages = [22,5,17];
const sorted = [...ages].sort((a,b) => a-b);
```
تمرین: کاربران را بر اساس سن نزولی مرتب کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
