# درس 7: تبدیل نوع

از `Number()`, `String()`, `Boolean()`, `parseInt()` و `parseFloat()` برای تبدیل استفاده می‌شود.

```js
Number("18"); // 18
parseInt("25px", 10); // 25
parseFloat("20.2kg"); // 20.2
Number("abc"); // NaN
```
تمرین: ورودی رشته‌ای مبلغ را تبدیل و اعتبارسنجی کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
