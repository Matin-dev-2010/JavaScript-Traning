# درس 13: الگوهای ترکیبی

متدها را می‌توان زنجیره کرد. `filter()` و `map()` آرایه جدید می‌سازند.

```js
const adminNames = users.filter(u => u.role === "admin").map(u => u.name);
```
تمرین: نام کاربران فعال را استخراج کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
