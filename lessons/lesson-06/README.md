# درس 6: توابع و scope

تابع کد قابل استفاده مجدد است. پارامتر در تعریف می‌آید، آرگومان هنگام فراخوانی فرستاده می‌شود و `return` مقدار را برمی‌گرداند.

```js
function greet(name) { return `Hello, ${name}`; }
const double = n => n * 2;
```
تمرین: تابعی برای محاسبه قیمت × تعداد بساز.
