# درس ۱۰ — مدیریت خطا

## چرا مدیریت خطا؟
ورودی نامعتبر، شناسهٔ پیدا نشده یا خطای فایل/شبکه ممکن است رخ دهد. برنامهٔ قابل اتکا باید خطا را قابل فهم کند و از ادامهٔ اجرای نامعتبر جلوگیری کند.

## ۱. throw و Error
```js
function divide(a, b) {
  if (b === 0) throw new Error("تقسیم بر صفر مجاز نیست");
  return a / b;
}
```
`throw` جریان عادی را متوقف می‌کند و خطا را به نزدیک‌ترین `catch` منتقل می‌کند. بهتر است شیء `Error` پرتاب کنیم تا پیام و stack trace داشته باشیم.

## ۲. try و catch
```js
try {
  const result = divide(10, 0);
  console.log(result);
} catch (error) {
  console.error("عملیات ناموفق بود:", error.message);
}
```
کد مشکوک به خطا داخل `try` است و `catch` آن را مدیریت می‌کند. در کد واقعی، پیام داخلی حساس را بی‌محابا به کاربر نهایی نشان نده.

## ۳. finally
```js
try {
  console.log("شروع");
} catch (error) {
  console.error(error);
} finally {
  console.log("این بخش در پایان اجرا می‌شود");
}
```
`finally` برای پاک‌سازی منابع مناسب است و چه خطا رخ دهد چه ندهد اجرا می‌شود، با استثناهای مربوط به توقف فرایند.

## ۴. اعتبارسنجی ورودی
```js
function createUser(name) {
  if (typeof name !== "string" || name.trim() === "") {
    throw new Error("نام باید رشتهٔ غیرخالی باشد");
  }
  return { name: name.trim() };
}
```
اعتبارسنجی نزدیک به مرز ورود داده انجام می‌شود. تابع سرویس نیز باید قواعد ضروری را حفظ کند، حتی اگر رابط کاربری قبلاً اعتبارسنجی کرده باشد.

## ۵. چه زمانی خطا را نگیریم؟
نگرفتن خطا باعث می‌شود فراخواننده تصمیم بگیرد چه کند. گاهی این بهترین طراحی است. از `catch` خالی پرهیز کن؛ خطا را یا مدیریت کن، یا با اطلاعات مناسب دوباره پرتاب کن.

## اشتباهات رایج
- پرتاب رشته به‌جای `Error`.
- گرفتن خطا و نادیده گرفتن کامل آن.
- استفاده از `try/catch` برای جایگزینی اعتبارسنجی عادی.
- نشان دادن جزئیات داخلی سرور به کاربر.

## تمرین
تابع ساخت کاربر بنویس که نام خالی و سن غیرصحیح یا منفی را رد کند. سپس آن را با `try/catch` فراخوانی کن و پیام خطا را چاپ کن.

## پاسخ نمونه
```js
function createUser(name, age) {
  if (typeof name !== "string" || !name.trim()) throw new Error("نام نامعتبر است");
  if (!Number.isInteger(age) || age <= 0) throw new Error("سن نامعتبر است");
  return { name: name.trim(), age };
}
try {
  console.log(createUser("", 20));
} catch (error) {
  console.error(error.message);
}
```

## مرور
می‌توانم خطا را با پیام مناسب پرتاب کنم، در لایهٔ درست بگیرم و خطا را بی‌صدا پنهان نکنم.
