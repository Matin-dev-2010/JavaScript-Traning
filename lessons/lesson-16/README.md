# درس ۱۶ — جست‌وجو و زنجیره‌سازی

## ۱. جست‌وجو بر اساس شناسه
```js
function getUserById(id) {
  return users.find(user => user.id === id) ?? null;
}
```
از مقایسهٔ سخت‌گیرانه استفاده می‌کنیم. اگر شناسه از فرم به شکل رشته بیاید، `"2"` با عدد `2` برابر سخت‌گیرانه نیست؛ باید در مرز ورودی شناسه را اعتبارسنجی/تبدیل کنیم.

## ۲. جست‌وجوی متنی بدون حساسیت به حروف
```js
function searchUsers(searchTerm) {
  if (typeof searchTerm !== "string") {
    throw new Error("عبارت جست‌وجو باید رشته باشد");
  }
  const term = searchTerm.trim().toLowerCase();
  if (!term) return [...users];
  return users.filter(user => user.name.toLowerCase().includes(term));
}
```
در این قرارداد، عبارت خالی همهٔ کاربران را برمی‌گرداند. می‌توان تصمیم دیگری گرفت، اما رفتار باید مشخص و مستند باشد.

## ۳. ترکیب چند شرط
```js
const result = users
  .filter(user => user.isActive && user.role === "admin")
  .sort((a, b) => b.age - a.age)
  .map(user => user.name);
```
ابتدا مدیران فعال انتخاب می‌شوند، سپس بر اساس سن نزولی مرتب می‌شوند و در پایان فقط نام‌ها می‌مانند. چون `filter` آرایهٔ جدید ساخته، `sort` در این زنجیره آرایهٔ اولیه را مرتب نمی‌کند.

## ۴. بعضی، همه، و اولین مورد
- `some`: آیا دست‌کم یک عضو شرط را دارد؟
- `every`: آیا همهٔ اعضا شرط را دارند؟ برای آرایهٔ خالی `true` است.
- `find`: اولین عضو مطابق شرط.
- `filter`: همهٔ اعضای مطابق شرط.
- `includes`: آیا مقدار مشخص در آرایه هست؟

## ۵. طراحی تابع‌های جست‌وجو
نام تابع باید هدف را روشن کند؛ ورودی‌ها اعتبارسنجی شوند؛ خروجی در همهٔ حالت‌ها قرارداد یکسانی داشته باشد. برای مثال `getUserById` می‌تواند همیشه شیء یا `null` برگرداند، در حالی که `searchUsers` همیشه آرایه می‌دهد.

## ۶. پیچیدگی و کارایی
`find`, `filter` و `some` معمولاً از ابتدای آرایه بررسی می‌کنند و در بدترین حالت همهٔ اعضا را می‌بینند؛ پیچیدگی خطی `O(n)` دارند. برای مجموعه‌های کوچک کاملاً مناسب‌اند. بهینه‌سازی ساختار داده را زمانی انجام بده که نیاز واقعی روشن شده باشد.

## تمرین
تابع `getActiveAdmins` بنویس که مدیران فعال را بر اساس سن نزولی مرتب کند و فقط نامشان را برگرداند. همچنین `searchUsers` را برای عبارت خالی و ورودی نامعتبر آزمایش کن.

## پاسخ نمونه
```js
function getActiveAdmins() {
  return users
    .filter(user => user.isActive && user.role === "admin")
    .sort((a, b) => b.age - a.age)
    .map(user => user.name);
}
```

## مرور
می‌توانم روش جست‌وجو را با نوع خروجی موردنیاز انتخاب کنم و زنجیره‌ای خوانا از عملیات بسازم.
