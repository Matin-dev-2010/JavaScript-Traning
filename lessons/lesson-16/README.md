# درس 16: جست‌وجو و زنجیره متدها

متن ورودی را با `trim()` و `toLowerCase()` نرمال‌سازی کن. از `filter()` برای همه نتایج و `find()` برای اولین نتیجه استفاده کن.

```js
const result = users.filter(u => u.name.toLowerCase().includes(term.trim().toLowerCase()));
```
تمرین: جست‌وجو را بدون حساسیت به بزرگی حروف بساز.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
