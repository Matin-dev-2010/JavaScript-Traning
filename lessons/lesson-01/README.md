# درس ۱ — مبانی JavaScript، متغیرها و انواع داده

## هدف درس
در این درس یاد می‌گیری JavaScript چه نقشی دارد، چطور داده‌ها را در متغیرها نگه داریم و چطور مقدارهای پایه را تشخیص دهیم. این مفاهیم پایهٔ تمام درس‌های بعدی و پروژهٔ User Management هستند.

## ۱. JavaScript چیست؟
JavaScript زبانی برای تعریف رفتار برنامه‌هاست. در مرورگر برای تعامل با صفحه و در محیط Node.js برای ساخت برنامه‌های سمت سرور و API هم استفاده می‌شود. کد JavaScript معمولاً دستورها را به ترتیب اجرا می‌کند، مگر آنکه شرط، حلقه، تابع یا عملیات ناهم‌زمان مسیر اجرا را تغییر دهد.

## ۲. تعریف متغیر با const و let
```js
const appName = "User Management";
let userCount = 0;
userCount = userCount + 1;
console.log(appName, userCount);
```
- `const`: اتصال متغیر را نمی‌توان دوباره به مقدار دیگری اختصاص داد.
- `let`: امکان انتساب دوباره وجود دارد.
- از `var` در کدهای جدید معمولاً پرهیز می‌کنیم، چون قواعد محدودهٔ آن می‌تواند گیج‌کننده باشد.
نکته: `const` به معنی ثابت بودن عمیق یک شیء نیست؛ فقط انتساب دوبارهٔ همان متغیر را ممنوع می‌کند.

## ۳. انواع دادهٔ پایه
```js
const name = "Sara";       // string
const age = 22;            // number
const isActive = true;     // boolean
const missing = undefined; // مقدار تعریف‌نشده
const empty = null;        // نبودن عمدی مقدار
console.log(typeof name);  // "string"
console.log(typeof age);   // "number"
```
انواع رایج دیگر شامل `bigint` و `symbol` هستند. آرایه‌ها و اشیاء از نوع object محسوب می‌شوند. یک نکتهٔ تاریخی جاوااسکریپت: `typeof null` مقدار `"object"` می‌دهد؛ این رفتار قدیمی زبان است.

## ۴. رشته و قالب‌بندی
رشته را می‌توان با کوتیشن تکی یا دوتایی ساخت. برای قرار دادن متغیر در متن، از template literal استفاده کن:
```js
const userName = "Ali";
const message = `سلام ${userName}، خوش آمدی.`;
console.log(message);
```
عبارت داخل `${...}` محاسبه می‌شود؛ بنابراین می‌توان نوشت `${2 + 3}`.

## ۵. عملگرها و خروجی
```js
const price = 120;
const quantity = 2;
console.log(price * quantity); // 240
console.log("سن:", 18);
```
عملگرهای متداول ریاضی `+`, `-`, `*`, `/`, `%` هستند. عملگر `+` هم جمع عددی انجام می‌دهد و هم ممکن است رشته‌ها را به هم بچسباند؛ پس نوع داده مهم است.

## اشتباهات رایج
- استفاده از `=` به جای مقایسه: `=` انتساب است.
- استفاده از `const` و سپس تلاش برای انتساب دوباره.
- فرض اینکه عدد داخل رشته حتماً عدد است؛ `"22"` رشته است، نه number.
- فراموش کردن تفاوت `null` و `undefined`.

## تمرین
۱. متغیرهای `name`, `age`, `isStudent` بساز و نوع هرکدام را چاپ کن.
۲. با template literal جمله‌ای بساز که نام و سن را نشان دهد.
۳. قیمت یک کالا و تعداد آن را تعریف و مبلغ نهایی را محاسبه کن.

## پاسخ نمونه
```js
const name = "Matin";
const age = 16;
const isStudent = true;
console.log(typeof name, typeof age, typeof isStudent);
console.log(`${name} ${age} سال دارد.`);
console.log(250 * 3);
```

## مرور
- می‌توانم تفاوت `const` و `let` را توضیح دهم.
- می‌توانم string، number و boolean را تشخیص دهم.
- می‌توانم از template literal استفاده کنم.
- می‌توانم خروجی را با `console.log` بررسی کنم.
