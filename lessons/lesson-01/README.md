# درس 1: مبانی JavaScript و متغیرها

`const` برای binding ثابت و `let` برای binding قابل‌تغییر است. انواع رایج: string, number, boolean, undefined, null, object.

```js
const name = "Matin";
let age = 16;
console.log(`${name} is ${age} years old.`);
```
تمرین: نام، سن و علاقه‌مندی خود را با template literal چاپ کن.
