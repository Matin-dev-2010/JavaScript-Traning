# درس ۸ — Truthy، falsy، null و undefined

## ۱. undefined و null
- `undefined`: معمولاً یعنی مقداری تعیین نشده یا ویژگی وجود ندارد.
- `null`: معمولاً برای نشان دادن نبودن عمدی یک مقدار استفاده می‌شود.
```js
let selectedUser;
const user = { name: "Ali" };
console.log(selectedUser); // undefined
console.log(user.email);  // undefined
const selected = null;
```
در پروژه، می‌توانیم برای کاربر پیدا نشده `null` برگردانیم تا نتیجه روشن باشد.

## ۲. Truthy و falsy
در شرط‌ها هر مقدار به‌صورت ضمنی به boolean تبدیل می‌شود:
```js
if ("hello") console.log("اجرا می‌شود");
if (0) console.log("اجرا نمی‌شود");
```
مقادیر falsy: `false`, `0`, `-0`, `0n`, رشتهٔ خالی، `null`, `undefined`, `NaN`. آرایهٔ خالی `[]` و شیء خالی `{}` truthy هستند.

## ۳. عملگر OR یا ||
```js
const displayName = inputName || "مهمان";
```
اگر `inputName` falsy باشد، مقدار سمت راست انتخاب می‌شود. این رفتار برای مقدار صفر یا رشتهٔ خالی ممکن است ناخواسته باشد.

## ۴. Nullish coalescing یا ??
```js
const retryCount = suppliedCount ?? 3;
```
`??` فقط زمانی مقدار پیش‌فرض را انتخاب می‌کند که سمت چپ `null` یا `undefined` باشد:
```js
console.log(0 || 10);  // 10
console.log(0 ?? 10);  // 0
console.log("" || "مهمان"); // مهمان
console.log("" ?? "مهمان"); // رشتهٔ خالی
```
وقتی صفر و رشتهٔ خالی داده‌های معتبرند، `??` معمولاً انتخاب دقیق‌تری است.

## ۵. مقدار بازگشتی در جست‌وجو
```js
const user = users.find(u => u.id === 99);
if (user === undefined) {
  console.log("کاربر پیدا نشد");
}
```
می‌توانیم نتیجه را با `?? null` نرمال کنیم. برای کد قابل پیش‌بینی، قرارداد خروجی تابع را ثابت نگه دار.

## اشتباهات رایج
- فرض اینکه `[]` یا `{}` falsy هستند.
- استفاده از `||` برای مقادیری که صفر معتبر است.
- یکسان دانستن `null` و `undefined`.
- استفاده از شرط ساده برای بررسی وجود یک شیء بدون فهم قرارداد تابع.

## تمرین
نتیجهٔ ورودی‌های `0`, `""`, `null`, `undefined`, `[]` و `{}` را با `Boolean` چاپ کن و خروجی `||` و `??` را مقایسه کن.

## مرور
می‌توانم برای مقدار پیش‌فرض درست انتخاب کنم و تفاوت نبودن مقدار با مقدار falsy را تشخیص دهم.
