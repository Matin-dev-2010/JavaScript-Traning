# درس 8: Truthy، falsy، null و undefined

Falsyها شامل `false`, `0`, `""`, `null`, `undefined` و `NaN` هستند. آرایه و آبجکت خالی truthy هستند. `undefined` معمولاً مقدار تعیین‌نشده و `null` نبود مقدار عمدی را نشان می‌دهد.

```js
Boolean(""); // false
Boolean([]); // true
```
تمرین: ورودی خالی را از ورودی معتبر تشخیص بده.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
