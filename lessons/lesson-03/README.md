# درس ۳ — آرایه‌ها و حلقه‌ها

## هدف
آرایه برای نگهداری مجموعه‌ای مرتب از مقدارهاست. فهرست کاربران پروژه نیز مجموعه‌ای از اشیاء خواهد بود.

## ۱. ساخت و دسترسی به آرایه
```js
const names = ["Ali", "Sara", "Reza"];
console.log(names[0]); // Ali
console.log(names.length); // 3
```
اندیس از صفر شروع می‌شود؛ آخرین اندیس برابر `length - 1` است. دسترسی به اندیس ناموجود معمولاً `undefined` برمی‌گرداند.

## ۲. تغییر آرایه
```js
const names = ["Ali", "Sara"];
names.push("Reza"); // افزودن به انتها
names.pop();        // حذف آخر
names.unshift("Mina"); // افزودن به ابتدا
names.shift();         // حذف ابتدا
```
این متدها خود آرایه را تغییر می‌دهند. اگر آرایه با `const` تعریف شده باشد، می‌توان محتوایش را تغییر داد؛ فقط نمی‌توان متغیر را به آرایهٔ دیگری منتسب کرد.

## ۳. حلقهٔ for
```js
const users = ["Ali", "Sara", "Reza"];
for (let i = 0; i < users.length; i++) {
  console.log(i, users[i]);
}
```
بخش اول مقدار اولیه، بخش دوم شرط ادامه، و بخش سوم تغییر شمارنده است. اشتباه در شرط ممکن است حلقهٔ بی‌نهایت بسازد.

## ۴. for...of
برای پیمایش مقدارها:
```js
for (const name of users) {
  console.log(name);
}
```
وقتی به اندیس نیاز نداری، این روش ساده‌تر است. برای پیمایش کلیدهای یک شیء از `for...in` استفاده می‌شود، اما برای آرایه‌ها معمولاً `for...of` مناسب‌تر است.

## ۵. آرایه‌ای از اشیاء
```js
const users = [
  { id: 1, name: "Ali", age: 20 },
  { id: 2, name: "Sara", age: 22 }
];
for (const user of users) {
  console.log(user.name, user.age);
}
```
هر عضو آرایه یک شیء است؛ برای رسیدن به نام کاربر از `user.name` استفاده می‌کنیم.

## ۶. break و continue
- `break` حلقه را متوقف می‌کند.
- `continue` به تکرار بعدی می‌رود.
از آن‌ها فقط وقتی استفاده کن که منطق را واضح‌تر می‌کنند.

## تمرین
از آرایهٔ کاربران، نام همه را چاپ کن؛ سپس فقط کاربران بالای ۱۸ سال را با یک حلقه نمایش بده. در مرحلهٔ دوم تعداد کاربران را نیز بشمار.

## پاسخ نمونه
```js
const users = [
  { id: 1, name: "Ali", age: 20 },
  { id: 2, name: "Reza", age: 17 }
];
let count = 0;
for (const user of users) {
  console.log(user.name);
  if (user.age > 18) count++;
}
console.log("بالای ۱۸ سال:", count);
```

## اشتباهات رایج
- شروع اندیس از ۱.
- استفاده از `i <= array.length` که یک بار اضافه اجرا می‌شود.
- تغییر آرایه هنگام پیمایش بدون توجه به اثر آن.
- اشتباه گرفتن اندیس با مقدار عضو.

## مرور
می‌توانم آرایه بسازم، اعضایش را بخوانم و با حلقه‌ها مجموعه‌ای از داده‌ها را پردازش کنم.
