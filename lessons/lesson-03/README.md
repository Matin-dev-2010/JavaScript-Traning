# درس 3: آرایه‌ها و حلقه‌ها

آرایه مجموعه‌ای مرتب از مقادیر است. `for`, `for...of` و `while` برای پیمایش استفاده می‌شوند.

```js
const numbers = [10, 20, 30];
let sum = 0;
for (const n of numbers) sum += n;
console.log(sum);
```
تمرین: مجموع آرایه و تعداد اعضای آن را محاسبه کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
