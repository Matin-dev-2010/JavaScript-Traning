# درس 9: Optional chaining و nullish coalescing

`?.` دسترسی امن می‌دهد و `??` فقط برای null/undefined مقدار پیش‌فرض می‌گذارد؛ `||` برای همه مقادیر falsy فعال می‌شود.

```js
const user = {profile:null};
user.profile?.city;
0 ?? 10; // 0
0 || 10; // 10
```
تمرین: شهر کاربر را امن بخوان و پیش‌فرض بده.
