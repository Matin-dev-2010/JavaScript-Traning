# درس ۴ — متدهای مهم آرایه

## چرا این متدها؟
به‌جای نوشتن حلقه برای هر کار ساده، متدهای آرایه نیت کد را روشن می‌کنند. در پروژه از آن‌ها برای نمایش نام‌ها، فیلتر کاربران و پیدا کردن یک کاربر استفاده می‌کنیم.

## ۱. map
برای تبدیل هر عضو به مقدار جدید و ساخت آرایه‌ای تازه:
```js
const ages = [18, 20, 25];
const nextYear = ages.map(age => age + 1);
console.log(nextYear); // [19, 21, 26]
```
تعداد اعضای خروجی معمولاً برابر ورودی است. `map` را برای تبدیل استفاده کن، نه صرفاً اجرای کار جانبی.

## ۲. filter
برای انتخاب اعضایی که شرط را برآورده می‌کنند:
```js
const users = [
  { id: 1, name: "Ali", age: 20 },
  { id: 2, name: "Reza", age: 17 }
];
const adults = users.filter(user => user.age >= 18);
```
خروجی آرایه‌ای جدید است؛ خود آرایهٔ اولیه حذف یا فیلتر نمی‌شود. با این حال اگر اعضا شیء باشند، مرجع همان اشیاء در آرایهٔ جدید قرار می‌گیرد.

## ۳. find
اولین عضو منطبق را برمی‌گرداند:
```js
const user = users.find(user => user.id === 2);
console.log(user); // شیء Reza
```
اگر چیزی پیدا نشود، نتیجه `undefined` است. پس هنگام استفاده باید نبودن نتیجه را در نظر بگیری.

## ۴. some و includes
```js
const hasMinor = users.some(user => user.age < 18);
const roles = ["admin", "user"];
console.log(roles.includes("admin"));
```
`some` بررسی می‌کند آیا دست‌کم یک عضو شرط را دارد. `includes` وجود یک مقدار مشخص را بررسی می‌کند.

## ۵. زنجیره کردن
```js
const activeNames = users
  .filter(user => user.age >= 18)
  .map(user => user.name);
```
هر خط خروجی مرحلهٔ قبلی را دریافت می‌کند. زنجیره‌ها را مرحله‌ای و خوانا بنویس.

## نکات و اشتباهات
- `map` برای تبدیل است؛ `filter` برای انتخاب.
- `find` یک عضو می‌دهد؛ `filter` آرایه می‌دهد.
- نتیجهٔ `find` در صورت عدم یافتن `undefined` است.
- شرط callback باید نتیجهٔ مورد انتظار بدهد.
- این متدها معمولاً آرایهٔ اصلی را تغییر نمی‌دهند، اما ممکن است اشیاء خروجی همچنان مرجع مشترک داشته باشند.

## تمرین
از آرایهٔ کاربران، آرایهٔ نام کاربران فعال بساز؛ کاربر با شناسهٔ ۳ را پیدا کن؛ بررسی کن آیا کاربر غیرفعال وجود دارد؛ و نقش‌های مجاز را با `includes` بررسی کن.

## پاسخ نمونه
```js
const activeNames = users.filter(u => u.isActive).map(u => u.name);
const user3 = users.find(u => u.id === 3) ?? null;
const hasInactive = users.some(u => !u.isActive);
```

## مرور
می‌توانم تشخیص دهم برای تبدیل، فیلتر، جست‌وجوی یک عضو یا بررسی وجود یک شرط از کدام متد استفاده کنم.
