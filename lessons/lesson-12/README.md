# درس 12: Destructuring پیشرفته و rest/spread

مقدار پیش‌فرض در destructuring برای undefined اعمال می‌شود. Rest باقی‌مانده‌ها را جمع می‌کند و spread اعضا را باز می‌کند.

```js
const {name, role = "user"} = {name:"Ali"};
const [first, ...rest] = [10,20,30];
const copy = [...rest, 40];
```
تمرین: اولین عضو و باقی آرایه را جدا کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
