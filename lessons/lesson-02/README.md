# درس ۲ — شرط‌ها و منطق

## هدف
برنامه باید بتواند بر اساس وضعیت ورودی تصمیم بگیرد. شرط‌ها مسیر اجرای کد را تغییر می‌دهند و در اعتبارسنجی کاربر، سطح دسترسی و وضعیت حساب کاربرد دارند.

## ۱. if و else
```js
const age = 20;
if (age >= 18) {
  console.log("بزرگسال");
} else {
  console.log("زیر ۱۸ سال");
}
```
شرط داخل پرانتز به مقدار منطقی تبدیل می‌شود. اگر درست باشد، بلوک اول اجرا می‌شود؛ در غیر این صورت بلوک `else`.

## ۲. else if
برای چند حالت:
```js
const score = 82;
if (score >= 90) {
  console.log("عالی");
} else if (score >= 70) {
  console.log("خوب");
} else if (score >= 50) {
  console.log("نیاز به تمرین");
} else {
  console.log("تلاش دوباره");
}
```
شرط‌ها از بالا به پایین بررسی می‌شوند و نخستین شرط درست انتخاب می‌شود؛ ترتیب شرط‌ها اهمیت دارد.

## ۳. مقایسه
- `===`: برابری مقدار و نوع.
- `!==`: نابرابری مقدار یا نوع.
- `>`, `<`, `>=`, `<=`: مقایسهٔ عددی یا ترتیب رشته‌ای.
ترجیح بده از مقایسهٔ سخت‌گیرانه استفاده کنی:
```js
console.log(5 === "5"); // false
console.log(5 == "5");  // true؛ تبدیل نوع ضمنی
```
`==` ممکن است تبدیل نوع غیرمنتظره انجام دهد.

## ۴. عملگرهای منطقی
```js
const age = 21;
const hasTicket = true;
console.log(age >= 18 && hasTicket); // هر دو شرط باید درست باشند
console.log(age < 18 || hasTicket);  // دست‌کم یکی درست باشد
console.log(!hasTicket);             // برعکس کردن نتیجه
```
- `&&`: AND
- `||`: OR
- `!`: NOT
این عملگرها short-circuit هستند؛ ممکن است با توجه به نتیجهٔ سمت چپ، سمت راست ارزیابی نشود.

## ۵. شرط در پروژه
```js
const user = { role: "admin", isActive: true };
if (user.isActive && user.role === "admin") {
  console.log("کاربر مدیر فعال است");
} else {
  console.log("دسترسی این بخش مجاز نیست");
}
```
این مثال صرفاً منطق آموزشی است؛ امنیت واقعی باید در سمت سرور هم بررسی شود.

## ۶. عملگر سه‌تایی
برای انتخاب ساده:
```js
const age = 17;
const status = age >= 18 ? "بزرگسال" : "نوجوان";
```
شرط‌های پیچیده را با ternary تو در تو ننویس؛ خوانایی مهم‌تر از کوتاه بودن کد است.

## اشتباهات رایج
- نوشتن `if (age = 18)` به جای `age === 18`.
- فراموش کردن اینکه `&&` یعنی همهٔ شرط‌ها.
- قرار دادن شرط کلی قبل از شرط خاص‌تر.
- تصور اینکه مخفی کردن یک دکمه در رابط کاربری جای کنترل دسترسی سرور را می‌گیرد.

## تمرین
تابعی بنویس که سن را بگیرد: اگر منفی بود پیام نامعتبر، اگر کمتر از ۱۸ بود پیام «دسترسی محدود»، و در غیر این صورت «مجاز» برگرداند. سپس شرط مدیر فعال را با `&&` بررسی کن.

## پاسخ نمونه
```js
function checkAge(age) {
  if (age < 0) return "سن نامعتبر";
  if (age < 18) return "دسترسی محدود";
  return "مجاز";
}
console.log(checkAge(16));
```

## مرور
می‌توانم شرط‌های چندگانه، مقایسهٔ سخت‌گیرانه و عملگرهای منطقی را در یک مثال واقعی به کار ببرم.
