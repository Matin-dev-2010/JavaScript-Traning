# درس 2: شرط‌ها و منطق

از `if/else if/else` و عملگرهای `===`, `!==`, `&&`, `||`, `!` برای تصمیم‌گیری استفاده کن.

```js
const loggedIn = true;
if (loggedIn) console.log("Welcome");
else console.log("Please log in");
```
نکته: معمولاً `===` را به `==` ترجیح بده. تمرین: بر اساس سن پیام مناسب چاپ کن.
