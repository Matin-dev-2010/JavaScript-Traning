# درس 14: reduce()

`reduce()` آرایه را به یک مقدار نهایی تبدیل می‌کند. مقدار آغازین را مشخص کن.

```js
const total = [10,20,30].reduce((sum, n) => sum + n, 0);
```
تمرین: مجموع سن‌ها یا تعداد کاربران هر نقش را حساب کن.

## مرور
- [ ] مفهوم را بدون جزوه توضیح می‌دهم.
- [ ] مثال را خودم می‌نویسم.
- [ ] تمرین را با ورودی‌های مختلف آزمایش می‌کنم.
