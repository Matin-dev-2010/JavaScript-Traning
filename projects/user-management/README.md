# User Management

پروژه تمرینی برای آبجکت‌ها، آرایه‌ها، اعتبارسنجی، ES Modules و CRUD.

## اجرا
```bash
npm start
```

- `users.js`: داده اولیه
- `userService.js`: توابع مدیریت کاربران
- `app.js`: نمونه استفاده

داده‌ها فقط در حافظه نگهداری می‌شوند و با پایان اجرا از بین می‌روند. این پروژه هنوز API یا دیتابیس واقعی ندارد.
