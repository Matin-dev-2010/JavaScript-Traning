# JavaScript Training

مخزن آموزشی مسیر JavaScript تا شروع Backend Development.

- `lessons/lesson-01` تا `lessons/lesson-18`: جزوه، مثال و تمرین
- `projects/user-management`: پروژه عملی CRUD با ES Modules
- `ROADMAP.md`: نقشه راه ادامه یادگیری

## اجرا
```bash
cd projects/user-management
npm start
```
پیش‌نیاز: Node.js.

یادداشت: جزوه‌ها بر اساس مباحث ثبت‌شده در روند یادگیری بازسازی شده‌اند و لزوماً متن کلمه‌به‌کلمه تمام گفتگوهای قبلی نیستند. پروژه فعلاً از حافظه استفاده می‌کند، نه دیتابیس یا API واقعی.
